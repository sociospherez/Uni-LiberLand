# LDDS v2.1 — Student Enrolment Flow

## Added
- Four-stage application wizard with persistent browser progress
- Field-level validation for personal details and education
- Programme handoff from catalogue and Atlas
- Demonstration document validation for PDF, JPG and PNG files up to 5 MB
- Structured review screen with editable completed stages
- Applicant declaration before payment
- Validated payment simulation using the standard test card number
- Application and receipt reference generation
- Confirmation experience with clear next steps
- Student Hub handoff showing programme, application, payment and identity status

## Important demonstration constraints
- No document is uploaded or transmitted.
- No card details are sent or stored.
- No real payment is processed.
- Application data is retained only in the current browser through localStorage.
