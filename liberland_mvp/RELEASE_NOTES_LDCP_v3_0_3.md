# LDCP v3.0.3 — Architectural Admissions & Student Workspace

## Scope
Applies the approved Architectural design language to the complete enrolment and post-enrolment journey.

## Updated areas
- Online application and step navigation
- Application forms, validation and document area
- Review and declaration experience
- Payment demonstration and order summary
- Confirmation and references
- Student Workspace and orientation overview
- Light Studio and Graphite Studio coverage
- Responsive tablet and mobile behaviour

## Design changes
- Reduced visible container nesting
- Replaced rounded cards with dividers and aligned content blocks
- Standardised 4–6px geometry for controls
- Removed blue/navy surfaces from admissions and workspace views
- Added neutral paper and graphite surfaces
- Reduced shadows and border weight
- Preserved existing application, payment and browser-storage logic

## Demonstration note
No real payment, document upload or external data transfer occurs.
