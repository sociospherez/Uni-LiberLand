Programme overview

A practical foundation in spreadsheet modelling

This certificate introduces the principles behind well-structured spreadsheet models. Learners progress from spreadsheet design and core formulas to data preparation, scenario modelling and visual reporting, then bring those skills together in a small applied project.

No advanced Excel knowledge is expected. Familiarity with basic spreadsheet navigation—opening a workbook, entering data and using simple formulas—is helpful.

Who it is for

Designed for practical business use

Suitable for students, early-career professionals, administrators, project teams, entrepreneurs and career changers who need to organise information, analyse data or build simple business models in Excel.

Prerequisites: no formal prerequisite. Learners should have access to a recent version of Microsoft Excel and be comfortable using a computer.

Learning outcomes

By the end, learners should be able to

Structure a workbook so that inputs, calculations and outputs are easy to follow.
Use commonly required formulas and functions accurately.
Clean, organise and analyse tabular business data.
Build a simple model using assumptions and scenarios.
Present findings using appropriate tables, charts and summary outputs.
Review a spreadsheet for common errors and improve its clarity.

Practical learning

Learn by building, not only reading

Short guided exercises are embedded throughout the programme. Learners work with sample sales, cost and operational data, repair deliberately flawed spreadsheets, test scenarios and create a final decision-ready workbook.

Example final project
Build a simple 12-month business planning model using supplied revenue and cost assumptions. The learner creates an input area, calculation logic, scenario comparison and a one-page summary of the key results.
Assessment & completion

A straightforward completion model

Progress is checked through short knowledge checks and practical exercises. The final applied workbook demonstrates that the learner can combine the core techniques in a coherent model.

Proposed certificate requirement: complete all required learning units and practical activities, achieve the agreed pass threshold on knowledge checks, and submit the final applied project. The precise assessment policy and pass threshold can be confirmed before production launch.

When should a reference stay fixed?

When a formula is copied, Excel normally adjusts its references. In a model, some references—such as a tax rate or central assumption—need to remain fixed. This lesson introduces relative, absolute and mixed references through one small pricing model.
