# LDDS v2.1.5 — Premium Education Experience

## Purpose
A visual maturity release based on LDDS v2.1. The enrolment functionality is preserved while the public and student-facing experience becomes calmer, more readable, more human, and more recognisably educational.

## Main improvements
- New premium education typography using native system fonts; no Bootstrap or external framework dependency.
- Softer sentence-case hierarchy and improved long-form reading rhythm.
- More editorial homepage, catalogue, programme, Atlas, application, dashboard and research treatments.
- Softer 18–30px radii, restrained elevation and clearer whitespace.
- Improved course marketplace cards and scanning metadata.
- Atlas presented as a guided companion rather than another system panel.
- Research pages given a scholarly/editorial identity.
- Refined mobile layouts and action stacking.
- Purposeful, restrained motion with reduced-motion support.
- Full compatibility with LDDS v2.0 day/night theme tokens.

## Technical notes
- New file: `premium-experience.css`
- Existing application and payment simulation logic remains unchanged.
- No Bootstrap files or sample-template assets were copied into the product.
- The sample e-learning template was used only as visual research.
