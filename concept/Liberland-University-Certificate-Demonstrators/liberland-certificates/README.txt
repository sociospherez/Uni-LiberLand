LIBERLAND UNIVERSITY — CERTIFICATE DEMONSTRATORS
Version 1.0 / 29 September 2026

START HERE
Extract the ZIP completely, then open index.html in a modern browser.
No installation, server, sign-in or internet connection is needed.
Each course HTML contains its own styling, content and lesson code.
Keep the data folder beside the HTML files to use CSV downloads.

INCLUDED
index.html — searchable nine-certificate catalogue
9 certificate HTML files — complete prospectuses and one sample lesson each
data/ — 9 small fictional CSV datasets for sample lessons
courses.json — reusable structured programme content
CONTENT.md — complete curriculum and content/UX specification
QA.txt — scope and results of verification

DEMONSTRATE
1. Open the Excel reference from the catalogue.
2. Inspect the six modules: 2 + 4 + 3 + 3 + 2 + 2 = 16 hours.
3. Select Preview learning experience.
4. Follow Learn, Worked Example, Try It and Check.
5. Try a wrong answer to see specific feedback, then retry correctly.
6. Continue to the transfer exercise and suggested next lesson.
7. Return to the catalogue and inspect a longer programme.
Print a prospectus with the page button; module details expand for printing.

DESIGN PROVENANCE
The approved Excel file at /mnt/data/excel-certificate-demo.html was not
available in the local project or returned conversation attachments.
This reference reconstructs the recorded structure, 16-hour allocation
and approved five-step learning flow. The light/graphite architectural
visual treatment is an interpretation, not a verified exact reproduction.
The bundled source archives and synced project files were not changed.

SCOPE
These are reviewable content and experience demonstrators. Only one sample
lesson per certificate is implemented. Remaining lessons, full project
datasets, academic approval, tutor assessment, enrolment and certificate
issuance are outside this package. Assessment thresholds and online delivery
are explicit proposals. No accreditation or professional licence is claimed.
All sample data is fictional. No external requests or analytics are used.
Quiz choices reset on reload. This is not saved learner progress.

The full MVP application has not been integrated or modified.
